# Sovereign demonstration vault

This is a safe, synthetic vault for demonstrating Sovereign. Nothing here is
personal data. It contains linked research, decisions, projects, activity and
one deliberate contradiction so the Knowledge Map, Timeline, Constellation,
contextual Sovereign panel, and Quick Brain can all be demonstrated.

## Demo flow

1. Open **Projects/Motor Anomaly Detection** and use `Ctrl/Cmd+Shift+B`.
2. Ask: “What did I decide about the motor project?”
3. Ask: “What do I know about motor anomaly detection?”
4. Open the **Sovereign panel** and switch between Your brain, Timeline, and
   Constellation. Then open the Knowledge Map.
5. Ask: “Do I have contradictory information about motor sampling?”

## Install into Obsidian

Create/open this folder as a vault in Obsidian, then from the repository root:

```bash
./scripts/install.sh --vault "$(pwd)/demo-vault"
```

Reload Obsidian afterwards. The plugin will index these notes on startup.
